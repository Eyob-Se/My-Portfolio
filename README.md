# Eyob Seleshi — Portfolio

Personal portfolio website showcasing my work, skills, and development journey as a Software Engineer and Full-Stack Developer.

**Live website:** https://eyob-dev-portfolio.netlify.app/

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Prerequisites

- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Vite will print the local URL in your terminal.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Run lint checks

```bash
npm run lint
```

## Project Structure

This project uses Vite with React and TypeScript. The main application entry point is `src/main.tsx`.
